# Week 2 Solutions

These scripts complete the Python syntax and Week 2 variables, operators, and
conditions exercises.

## Index

### Python Syntax Workshop

- [Python syntax fundamentals](python_syntax_fundamentals.py) - Hello Python, identifiers, strings, comments, input, conditions, debugging, and the Student Welcome mini-project.
- [Extended guessing game](guessing_game.py) - three rounds, ten attempts per round, input validation, hints, and total-score feedback.
- [Worksheet questions and answers](worksheet_answers.md) - practical questions, identifier practice, declaration classifications, debugging corrections, knowledge checks, and syntax review.

### Variables, Operators, and Conditions

- [COM4013 Week 2 exercises](com4013_week_2.py) - all COM4013 exercises in one file, selected through a `match case` menu.

Each Python file includes the source document and the worksheet question that
the code answers.

The scripts use Python 3 and meaningful camelCase names to match the lab
worksheets.
